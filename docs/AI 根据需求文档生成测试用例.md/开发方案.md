# 推荐 Java

## 1. Apache Tika 原生就是 Java 生态

现在的输入源支持：

```text
md、txt、PPT、XLS、PDF
```

这些格式用 Tika 解析时，Java 集成最自然：

```java
AutoDetectParser parser = new AutoDetectParser();
BodyContentHandler handler = new BodyContentHandler(-1);
Metadata metadata = new Metadata();

try (InputStream stream = new FileInputStream(file)) {
    parser.parse(stream, handler, metadata, new ParseContext());
}

String text = handler.toString();
```

# MariaDB 10.11.14 注意点

MariaDB 10.11 支持 `JSON` 类型，但需要注意：
在 MariaDB 里，`JSON` 本质上是 `LONGTEXT` 的别名，并不像 MySQL 8 那样是原生二进制 JSON 类型。


## 方案一：仍然使用 JSON 类型

适合可读性更好：

```sql
metadata_json JSON,
output_json JSON,
risk_tags_json JSON
```

## 方案二：直接使用 LONGTEXT

适合兼容性更稳：

```sql
metadata_json LONGTEXT COMMENT '元数据JSON',
output_json LONGTEXT COMMENT 'AI输出JSON',
risk_tags_json LONGTEXT COMMENT '风险标签JSON'
```

使用：

```text
LONGTEXT 存 JSON 字符串
```

现在做 Demo，避免 MariaDB JSON 兼容细节影响开发。
