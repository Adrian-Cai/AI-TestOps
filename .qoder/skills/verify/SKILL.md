name: verify
description: 完整验证前后端——运行后端单元测试和前端类型检查+构建。在完成任务或提交前使用此技能确认代码无破坏性变更。
---

依次执行以下验证步骤，报告每一步的结果。任一步骤失败时立即停止并报告错误详情。

## 步骤

1. **后端测试**
   在项目根目录运行：
   ```bash
   ./mvnw test
   ```
   关注：测试通过数、失败数、Jacoco 覆盖率是否达标（line≥50%, branch≥30%）。

2. **前端类型检查与构建**
   在 `frontend/` 目录运行：
   ```bash
   cd frontend && npm run build
   ```
   关注：TypeScript 编译错误、Vite 构建是否成功。

## 输出格式

用表格汇总结果：

| 步骤 | 状态 | 详情 |
|------|------|------|
| 后端测试 | ✅/❌ | 通过 X 个，失败 Y 个 |
| 前端构建 | ✅/❌ | 构建成功/失败原因 |

全部通过时输出"验证通过"；有失败时输出"验证失败"并附上关键错误信息。
